# Week 5 Projects

This folder contains multiple frontend practice projects built using HTML, CSS, React, and Tailwind CSS.

The projects in this week focus on improving:

* Responsive Web Design
* Tailwind CSS Styling
* React Components and Props
* Dynamic Rendering using `map()`
* Reusable UI Components
* Grid Layouts
* HTML Table Design
* Mobile-First Development

## Projects Included

* Responsive Web Design using Tailwind CSS
* React Product Listing App
* React User Card Application
* HTML Table Design
* Student Marks Table

## Technologies Used

* HTML
* CSS
* Tailwind CSS
* React JS

## Purpose

The main purpose of these projects is to practice frontend development concepts by building small responsive applications and UI layouts.

These projects help in understanding:

* Component-based UI development
* Responsive design techniques
* Tailwind utility classes
* Structuring frontend applications
* Building reusable components
* Styling clean and modern interfaces

## Learning Outcome

By completing these projects, practical experience is gained in creating responsive and interactive frontend applications using modern web development tools.
