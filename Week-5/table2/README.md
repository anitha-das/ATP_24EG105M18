# Student Marks Table

This  contains a simple student marks table created using HTML and CSS.

The table demonstrates the usage of:

* Tables
* Rows and Columns
* Rowspan and Colspan
* Table Borders
* CSS Styling
* Subject-wise Marks Display

The purpose of this project is to understand how structured tables are created and styled using HTML and CSS.

---

# Learning Objectives

Through this project, the following concepts are practiced:

* Creating tables using HTML
* Using `rowspan` and `colspan`
* Styling tables with CSS
* Aligning table content
* Organizing subject-wise data
* Managing table layouts

---

# HTML Concepts Used

## Table Structure

The table includes:

* `<table>`
* `<thead>`
* `<tbody>`
* `<tr>`
* `<th>`
* `<td>`

---

## Rowspan

The `rowspan` attribute is used to merge rows for subjects like:

* Biology
* Chemistry
* Physics

---

## Colspan

The `colspan` attribute is used for the main heading section.

---

## CSS Styling

CSS is used for:

* Borders
* Padding
* Center alignment
* Table width
* Border collapsing
