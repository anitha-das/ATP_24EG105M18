# React Product Listing App

This project is a simple React application created for practicing React components, props, JSX, and rendering dynamic data.

The application displays a list of products using reusable React components and responsive layouts.

---

# Learning Objectives

Through this project, the following React concepts are practiced:

* Creating Functional Components
* Using Props in React
* Rendering Dynamic Data
* Using `map()` in React
* Component Reusability
* JSX Syntax
* Responsive Grid Layout
* Organizing React Project Structure

---

# Project Structure

The project contains:

* `App.jsx`
* `components/Product.jsx`
* `index.css`

---

# Application Overview

The application displays multiple product cards dynamically using product data stored inside an array.

Each product card contains:

* Product Title
* Category
* Price
* Rating Information

The products are displayed using a reusable `Product` component.

---

# Components Used

## App Component

The `App.jsx` file:

* Stores the products array
* Uses the `map()` method
* Sends product data to the `Product` component using props
* Displays products in a responsive grid layout

---

## Product Component

The `Product.jsx` component:

* Receives product data using props
* Uses destructuring for cleaner code
* Displays product information inside a styled card
