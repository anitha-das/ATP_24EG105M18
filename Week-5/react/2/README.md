# React User Card Application
This project is a simple React application created for practicing React components, props, reusable UI design, and responsive layouts using Tailwind CSS.

The application displays multiple user cards dynamically with a navigation bar and footer section.

---

# Learning Objectives

Through this project, the following React concepts are practiced:

* Creating Functional Components
* Using Props
* Component Reusability
* Rendering Lists using `map()`
* Responsive Layout Design
* Organizing Components
* Using Tailwind CSS for Styling

---

# Project Structure

The project contains:

* `App.jsx`
* `components/Nav.jsx`
* `components/User.jsx`
* `components/UserList.jsx`
* `components/Footer.jsx`

---

# Application Overview

The application contains:

* Navigation Bar
* User Card Section
* Footer Section

User information is displayed dynamically using reusable React components.

---

# Components Used

## Nav Component

The navigation component contains:

* Logo section
* Navigation links
* Responsive flex layout

---

## User Component

The user component displays:

* User Image
* User Name
* User Email

Props are used to send user data from parent component to child component.

---

## UserList Component

The `UserList` component:

* Stores the users array
* Uses `map()` to render multiple user cards
* Displays users using grid layout

---

## Footer Component

The footer component contains:

* Contact information
* Help section
* Additional details

---

# React Concepts Practiced

## Functional Components

All UI sections are created using React function components.

---

## Props

Props are used to pass user data between components.

## Dynamic Rendering

The `map()` method is used to display multiple user cards dynamically.
