# Responsive Web Design using Tailwind CSS

This project contains two responsive web pages created for practicing responsive web design using HTML and Tailwind CSS.

The webpages demonstrate the usage of:

* Responsive Grid Layout
* Tailwind CSS Utility Classes
* Navigation Bars
* Hero Sections
* Buttons
* Images
* Responsive Cards
* Footer Section
* Mobile-First Design

The purpose of this project is to understand how responsive layouts are created using Tailwind CSS.

---

# Learning Objectives

Through this project, the following concepts are practiced:

* Structure of an HTML document
* Responsive web design
* Using Tailwind CSS classes
* Grid layouts using Tailwind
* Mobile-first approach
* Styling buttons and sections
* Creating responsive webpages
* Organizing webpage content

# Down.html

## Description

The first webpage is a simple responsive landing page containing:

* Hero section
* Heading and paragraph
* Call-to-action button
* Three responsive sections
* Footer section

This page demonstrates responsive layout creation using Tailwind CSS grid utilities.

---

## Features Used

### Hero Section

A top section with heading, paragraph, and button.

### Responsive Grid

Grid layout changes according to screen size using Tailwind breakpoints.

### Buttons

Styled buttons using Tailwind utility classes.

### Footer

Simple footer section with copyright text.
