# HTML Table Design

This  contains a simple HTML table design created using HTML and CSS.

The table demonstrates the usage of:

* Tables
* Rows and Columns
* Table Borders
* CSS Styling
* Cell Spacing and Alignment
* Responsive Table Width

The purpose of this project is to understand how tables are created and styled using CSS.

---

# Learning Objectives

Through this project, the following concepts are practiced:

* Creating tables using HTML
* Using rows and columns
* Applying borders using CSS
* Aligning table content
* Using `colspan`
* Styling tables with CSS
* Organizing tabular data

---

The project contains:
