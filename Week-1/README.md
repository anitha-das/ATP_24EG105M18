# Week 1 JavaScript Programs

This repository contains basic JavaScript programs that I practiced in Week 1.
These programs focus on simple logic building, loops, arrays, functions, and object handling.

---

## Programs Included

### 1. Largest of Two Numbers

* Compare two numbers using `if-else`
* Print the largest number

### 2. Largest of Three Numbers

* Use nested `if-else`
* Find the biggest among three values

### 3. Sum of Array Elements

* Loop through an array
* Add all elements and print the total

### 4. Smallest Element in Array

* Traverse array
* Find the minimum value

### 5. Function: Find Largest of Three

* Created a function findBig(a, b, c)
* Returns the largest value

### 6. Function: Sum of Array

* Function findSum(arr)
* Returns sum of all elements

### 7. Function: Search Element

* Function searchElement(arr, search)
* Returns index if found, else "Not found"

## Employee Object Programs

### 8. Add New Employee

### 9. Remove Employee
